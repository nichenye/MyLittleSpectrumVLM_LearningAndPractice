操作如下：
~
在 Windows 搜索框输入 env，选择 “编辑系统环境变量”。
点击 “环境变量” 按钮。
在 “用户变量” 或 “系统变量” 区域，点击 “新建”。
在弹出的窗口中，变量名填 HF_ENDPOINT，变量值填 https://hf-mirror.com。
一路点击“确定”保存。之后新开的命令行窗口都会自动应用这个设置。
~

还改了一些generate.py里的内容：

变更文件： generate.py（输入构造部分）
旧代码（修改前）：
python
encoded_prompt = tokenizer.apply_chat_template([messages], tokenize=True, add_generation_prompt=True)

新代码（修改后）：
python
encoded_prompt = tokenizer.apply_chat_template([messages], tokenize=True, add_generation_prompt=True, return_tensors="pt")
tokens = encoded_prompt.input_ids.to(device)
