## 📄 数据文件结构说明文档（可直接复制使用）

> **用途**：记录 WASD 数据集的原始文件结构和处理后的文件结构，供后续 AI 辅助开发时快速理解数据格式。

### 一、原始数据（下载下来的数据）

#### 1.1 来源
- **数据集名称**：WASD (Wireless Anomaly Signal Dataset)
- **下载渠道**：IEEE DataPort 拆分版本（`36_LTE_1_part_1_of_10.zip`）
- **原始压缩包大小**：4.89 GB

#### 1.2 解压后的文件夹结构
```
36_LTE_1/                                    ← 根目录
├── bin/                                      ← I/Q 二进制数据存放处
│   └── IQ_2024-04-20T22-06-22_790713246.bin  ← I/Q 数据文件（示例）
│   └── IQ_2024-04-20T22-07-...bin            ← 共 505 个 .bin 文件
│   └── ...
├── IQ_2024-04-20T22-06-22_790713246.json     ← 元数据文件（示例）
├── IQ_2024-04-20T22-07-...json               ← 共 505 个 .json 文件
└── ...
```

#### 1.3 文件类型详解

| 文件类型 | 数量 | 说明 |
|---|---|---|
| `.bin` 文件 | 505 个 | **I/Q 原始数据**，二进制格式。存储的是基带信号的 **I（同相）** 和 **Q（正交）** 分量，交错存放（`I0, Q0, I1, Q1, ...`）。每个文件约 130 万个采样点（21 ms 时长）。 |
| `.json` 文件 | 505 个 | **元数据文件**，与 `.bin` 文件一一对应。包含采样频率、时间戳、校准参数（`iq_level_offset`, `reference_level`）等信息。 |
| `.zip` 文件 | 1 个 | 原始压缩包（`36_LTE_1_part_1_of_10.zip`），4.89 GB。 |

#### 1.4 原始数据关键参数

| 参数 | 值 |
|---|---|
| 采样频率 | 61.44 MHz（从 JSON 元数据中读取） |
| 每个文件采样点数 | 1,300,000 个 I/Q 采样点 |
| 时间长度 | 约 21 ms |
| 数据类型 | `int32`（读取时转为 `float64`） |
| I/Q 格式 | 交错存储：`[I0, Q0, I1, Q1, ...]` |

#### 1.5 原始数据的局限性
- **不含频谱图**：`.bin` 是原始时域信号，需要经过 STFT（短时傅里叶变换）才能得到频谱图。
- **不含异常标注**：这批数据是纯采集的 LTE 信号，**没有合成异常信号**，因此没有对应的边界框标签（Bounding Box）。
- **适用场景**：仅适合用来做“冒烟测试”或“从原始数据生成频谱图”的流程验证。

### 二、处理后数据（你生成的）

#### 2.1 生成方式
- 使用 **STFT（短时傅里叶变换）** 将 `.bin` 中的 I/Q 数据转换为频谱图矩阵。
- 参数参考 WASD 官方 Notebook（`WASD_abnormal_signal_generation.ipynb`）。
- 每个 `.bin` 文件生成一个对应的 `.npy` 频谱图文件和一个 `.csv` 标签文件。

#### 2.2 处理后的文件夹结构
```
36_LTE_1/
├── processed/                                 ← 处理后数据根目录
│   ├── spectrograms/                          ← 频谱图存放处
│   │   ├── IQ_2024-04-20T22-06-22_790713246.npy   ← 频谱图矩阵（示例）
│   │   ├── IQ_2024-04-20T22-07-...npy             ← 共 505 个 .npy 文件
│   │   └── ...
│   └── labels/                                ← 标签存放处
│       ├── IQ_2024-04-20T22-06-22_790713246.csv   ← 标签文件（示例）
│       ├── IQ_2024-04-20T22-07-...csv             ← 共 505 个 .csv 文件
│       └── ...
└── ...
```

#### 2.3 文件类型详解

| 文件类型 | 数量 | 说明 |
|---|---|---|
| `.npy` 文件 | 505 个 | **频谱图矩阵**，NumPy 二进制格式。存储的是 STFT 变换后的幅度谱（dB 值），二维矩阵。 |
| `.csv` 文件 | 505 个 | **标签文件**，文本格式。包含该频谱图的基本信息和标注（当前为占位）。 |

#### 2.4 频谱图（`.npy`）格式

| 属性 | 值 |
|---|---|
| 存储格式 | NumPy 二进制（`np.save`） |
| 数据类型 | `float32` |
| 矩阵维度 | 2D：`(频率bin数, 时间帧数)` |
| 频率bin数 | 由 `nperseg=3200` 和 `nfft=3200` 决定，约 1601 个 |
| 时间帧数 | 由信号长度和窗口参数决定，约 200-300 帧 |
| 数值含义 | 幅度谱的 dB 值（`20 * log10(magnitude)`） |
| 频率轴 | 已做 `fftshift`，零频在矩阵中央 |
| 典型数值范围 | -80 dB ~ 0 dB |

**加载方式**：
```python
import numpy as np
spectrogram = np.load("IQ_2024-04-20T22-06-22_790713246.npy")
print(spectrogram.shape)  # 例如 (1601, 280)
```

#### 2.5 标签文件（`.csv`）格式

| 字段名 | 类型 | 说明 |
|---|---|---|
| `filename` | str | 对应的频谱图文件名（`xxx.npy`） |
| `height` | int | 频谱图矩阵的高度（频率bin数） |
| `width` | int | 频谱图矩阵的宽度（时间帧数） |
| `has_anomaly` | bool | 是否有异常信号（**当前默认为 False**） |

**当前状态说明**：
- 这批 `.csv` 文件是**占位标签**，因为原始 `.bin` 数据中不含合成异常信号。
- `has_anomaly` 字段全部为 `False`，表示无异常。
- 后续若需做异常检测任务，需要**叠加合成异常信号**（tone/chirp/pulse）并更新 `.csv` 中的标注信息。

**加载方式**：
```python
import pandas as pd
df = pd.read_csv("IQ_2024-04-20T22-06-22_790713246.csv")
print(df.head())
```

### 三、原始数据 → 处理后数据的对应关系

| 原始文件 | 处理后文件 |
|---|---|
| `bin/IQ_2024-04-20T22-06-22_790713246.bin` | `processed/spectrograms/IQ_2024-04-20T22-06-22_790713246.npy` |
| | `processed/labels/IQ_2024-04-20T22-06-22_790713246.csv` |

- **命名规则**：保持一致，仅后缀名不同（`.bin` → `.npy` / `.csv`）
- **一一对应**：505 个 `.bin` 文件 → 505 个 `.npy` + 505 个 `.csv`

---

### 四、重要说明（给后续 AI 的提示）

1. **这批数据不包含异常标注**：`has_anomaly` 全是 `False`。如果你想做异常检测任务，需要：
   - 参考 `WASD_abnormal_signal_generation.ipynb` 生成 tone/chirp/pulse 异常信号
   - 将异常信号叠加到原始 I/Q 数据上
   - 重新生成频谱图并更新 `.csv` 中的边界框坐标和异常类型

2. **频谱图未做标准化**：当前 `.npy` 存储的是原始 dB 值，范围约为 -80~0 dB。喂给 VLM 之前，需要做归一化处理（如缩放到 0~255 或标准正态分布）。

3. **后续工作建议**：
   - 用这批数据做 VLM 的**冒烟测试**（验证模型能吃频谱图格式）
   - 待完整 WASD 数据集（含异常标注）下载后，再替换为正式数据做消融实验
